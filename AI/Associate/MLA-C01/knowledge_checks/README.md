# 🧠 MLA-C01 Rapid Diagnostic Knowledge Checks

> **Certification:** AWS Certified Machine Learning Engineer - Associate (`MLA-C01`)  
> **Target Audience:** Students, engineers, and candidates preparing for MLA-C01.  
> **Format:** Module-by-module diagnostic checkpoints (10 questions each with collapsible `<details><summary>` rationales).

---

## 🗺️ Module Knowledge Checks Index

1. **[Module 01: Data Preparation for Machine Learning](./Module_01_Data_Preparation_Knowledge_Check.md)** (10 Questions)
   - SageMaker Feature Store (online/offline), Ordinal vs One-Hot encoding, vector chunking & overlap, RobustScaler, SMOTE, SageMaker Data Wrangler, Parquet, data leakage.
2. **[Module 02: ML Model Development](./Module_02_Model_Development_Knowledge_Check.md)** (10 Questions)
   - Low-Rank Adaptation (LoRA/PEFT), Distributed Data Parallelism (DDP), Model Parallelism, Bayesian HPO, ROUGE evaluation, early stopping, F1-Score, SageMaker Experiments, greedy decoding.
3. **[Module 03: Deployment & Orchestration of ML Workflows](./Module_03_Deployment_and_Orchestration_Knowledge_Check.md)** (10 Questions)
   - Real-Time vs Serverless vs Asynchronous vs Batch Transform, Multi-Model Endpoints (MME), SageMaker Model Registry approval gating, ConditionSteps in Pipelines, shadow deployments, BYOC contract (`/ping` & `/invocations`), Bedrock Agents.
4. **[Module 04: ML Solution Monitoring and Maintenance](./Module_04_Monitoring_and_Maintenance_Knowledge_Check.md)** (10 Questions)
   - Data drift vs concept drift, SageMaker Model Monitor baseline constraints, SHAP values & explainability, pre-training bias (DPPL), SageMaker Model Cards, Bedrock Guardrails & contextual grounding, indirect prompt injection, ISO/IEC 42001.
