# Lecture 04: Responsible AI & Model Governance

## ⏱️ Timing & Delivery Strategy
- **Duration:** 90 Minutes
- **Lecture Slide Deck:** `slides/Module_02_Amazon_Bedrock_and_RAG_Slides.md` (Part 2)
- **Hands-On Transition:** `labs/Lab_03_Responsible_AI_Bedrock_Guardrails.md`

## 🎯 Learning Objectives
1. Define the core pillars of Responsible AI: Fairness, Explainability, Robustness, Privacy, Transparency, and Safety.
2. Implement **Amazon Bedrock Guardrails**: Denied Topics, Content Filters (Hate, Insults, Sexual, Violence), Sensitive Information Filters (PII masking with regex and predefined entities), and Hallucination checks.
3. Detect bias and explain model predictions using **Amazon SageMaker Clarify** (SHAP feature attribution).
4. Track model lineage and governance using **Amazon SageMaker Model Cards** and **Model Dashboard**.
