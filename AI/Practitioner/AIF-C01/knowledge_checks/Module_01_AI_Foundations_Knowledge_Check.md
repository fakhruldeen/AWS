# Module 01 Knowledge Check: AI & ML Foundations

### Questions
1. **Which machine learning paradigm is used to predict continuous numerical values, such as future sales revenue?**
   - A) Classification
   - B) Regression
   - C) Clustering
   - D) Dimensionality Reduction
2. **What occurs when a model performs exceptionally well on training data but poorly on unseen test data?**
   - A) Underfitting
   - B) Overfitting
   - C) High Bias
   - D) Cold-start latency
3. **Which SageMaker capability allows users to build machine learning models using a visual drag-and-drop interface without writing code?**
   - A) SageMaker Canvas
   - B) SageMaker JumpStart
   - C) SageMaker Clarify
   - D) SageMaker Model Cards
4. **Which AWS service automatically converts spoken audio into written text?**
   - A) Amazon Polly
   - B) Amazon Transcribe
   - C) Amazon Comprehend
   - D) Amazon Rekognition
5. **Which metric is most critical when evaluating a medical diagnostic model where missing a positive disease diagnosis is life-threatening?**
   - A) Precision
   - B) Recall (Sensitivity)
   - C) Accuracy
   - D) Specificity

---

### Answer Key & Explanations
| Q# | Answer | Key Concept Reference |
| :---: | :---: | :--- |
| **1** | **B** | Regression predicts continuous quantitative values (sales, temperature, prices). |
| **2** | **B** | Overfitting occurs when a model learns noise in training data and fails to generalize. |
| **3** | **A** | SageMaker Canvas is AWS's no-code visual AutoML tool for business analysts. |
| **4** | **B** | Amazon Transcribe converts speech audio files or live streams into text transcripts. |
| **5** | **B** | High Recall minimizes False Negatives, ensuring actual positive cases are not missed. |
