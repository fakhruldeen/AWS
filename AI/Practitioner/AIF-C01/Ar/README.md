# الدليل العربي الشامل لشهادة AWS Certified AI Practitioner (`AIF-C01`)

مرحباً بك في الدليل التعليمي العربي الشامل والمفصّل لمسار شهادة **ممارس الذكاء الاصطناعي المعتمد من أمازون (`AWS Certified AI Practitioner — AIF-C01`)** وفق أحدث إصدار رسمي لدليل الاختبار (**الإصدار `v1.2` — أكتوبر 2026**). تم إعداد هذا الدليل بلغة عربية رصينة، واضحة، ومفصّلة تبسّط المفاهيم الهندسية والمعمارية للذكاء الاصطناعي وتعلّم الآلة والذكاء الاصطناعي التوليدي والوكلاء الأذكياء، مع الإبقاء على أسماء خدمات أمازون والمصطلحات التقنية باللغة الإنجليزية داخل صياغة عربية سليمة متوافقة تماماً مع اتجاه القراءة من اليمين إلى اليسار (`RTL`).

> [!NOTE]
> **منهجية هذا الدليل:**
> * **الوضوح والعمق الهندسي:** شرح تفصيلي لكل مفهوم وخدمة يشمل آلية العمل الداخلية، حالات الاستخدام الواقعية، الفروق الدقيقة بين الخيارات المتشابهة، وأشهر الفخاخ التي تتكرر في أسئلة الاختبار.
> * **الدقة المصطلحية واتجاه قراءة سليم:** تبدأ كل الفقرات والعناوين والنقاط باللغة العربية لضمان استقرار اتجاه النص (`RTL`) دون تداخل أو تشوّه عند قراءة المصطلحات الإنجليزية مثل [`Amazon Bedrock`](../AWS_AI_SERVICES_GLOSSARY.md#amazon-bedrock) و [`Amazon SageMaker AI`](../AWS_AI_SERVICES_GLOSSARY.md#amazon-sagemaker-ai).
> * **تغطية كاملة لتحديثات 2026 (`v1.2`):** يشمل الدليل أحدث خدمات ومفاهيم الاختبار الرسمي، بما فيها هندسة السياق (`Context Engineering`)، وبروتوكول سياق النماذج (`MCP`)، ومنصة الوكلاء (`Amazon Bedrock AgentCore`)، ومكتبة (`Strands Agents`)، وبيئة التطوير الوكيلة (`Kiro`)، وخدمة (`Amazon Quick`)، وخدمة (`AWS Transform`)، وتقطير النماذج (`Model Distillation`).

## بطاقة تعريفية باختبار `AIF-C01` الرسمي

| العنصر | التفاصيل الرسمية |
| :--- | :--- |
| **رمز الاختبار** | `AIF-C01` — شهادة ممارس الذكاء الاصطناعي المعتمد من `AWS` |
| **المستوى** | تأسيسي (`Foundational`) |
| **عدد الأسئلة** | 65 سؤالاً (50 سؤالاً مُقيّماً بالدرجات + 15 سؤالاً تجريبياً غير محسوب في النتيجة) |
| **المدة الزمنية** | 90 دقيقة (يمكن لغير الناطقين بالإنجليزية طلب 30 دقيقة إضافية مجانية عبر ميزة `ESL +30` قبل حجز الاختبار) |
| **درجة النجاح** | 700 من أصل 1000 درجة بنظام التقييم المتدرج (`Scaled Scoring`) |
| **أنماط الأسئلة الأربعة** | اختيار إجابة واحدة (`Multiple Choice`)، اختيار متعدد (`Multiple Response`)، الترتيب (`Ordering` من 3 إلى 5 خطوات)، والمطابقة (`Matching` من 3 إلى 7 أزواج) |

## خطة الدراسة الموصى بها خلال 10 أيام

1. **اليوم الأول والثاني:** قراءة ملف [التمهيد والأساسيات التقنية](./00_Prerequisites_Asasiyat_AlAI_walML.md) ثم التعمق في [المجال الأول](./01_Domain_1_Fundamentals_of_AI_and_ML.md)، مع حل أسئلة المجال الأول التدريبية.
2. **اليوم الثالث والرابع:** دراسة [المجال الثاني](./02_Domain_2_Fundamentals_of_GenAI.md) لفهم معمارية المحولات (`Transformers`)، والرموز (`Tokens`)، وهندسة السياق، والوكلاء الأذكياء، ومنظومة خدمات `AWS` التوليدية.
3. **اليوم الخامس والسادس:** التركيز المكثف على [المجال الثالث](./03_Domain_3_Applications_of_Foundation_Models.md) نظراً لكونه الأكبر وزناً في الاختبار (**28%**)، وإتقان `RAG`، وهندسة الأوامر، والضبط الدقيق، وتقطير النماذج، ومقاييس التقييم.
4. **اليوم السابع:** دراسة [المجال الرابع](./04_Domain_4_Responsible_AI.md) والتمييز الدقيق بين حواجز الحماية (`Bedrock Guardrails`) وأدوات كشف التحيز والتفسير (`SageMaker Clarify`) وبطاقات النماذج (`Model Cards`).
5. **اليوم الثامن:** دراسة [المجال الخامس](./05_Domain_5_Security_Compliance_and_Governance.md) واستيعاب نموذج المسؤولية المشتركة، وأمن الوكلاء، ومصفوفة نطاق أمن الذكاء الاصطناعي التوليدي.
6. **اليوم التاسع والعاشر:** مراجعة [دليل المقارنات الذهبية](./06_Exam_Tricks_and_Comparison_CheatSheet.md)، وحل تدريبات [الترتيب والمطابقة](../11_Practice_Exams/AIF_C01_Ordering_and_Matching_Drills.md)، وأهم [300 سؤال متكرر](../11_Practice_Exams/AIF_C01_Top_300_Most_Frequent_Exam_Questions.md)، ثم خوض [الاختبار التجريبي الكامل الثاني](../11_Practice_Exams/AIF_C01_Full_Length_Mock_Exam_2_v1.2.md) بزمن 90 دقيقة.
