### Question 1

**Domain:** `Domain 1: Cloud Concepts` | **ID:** `cc01`

> **Scenario:**  
> A company is moving from its own data center to AWS. Instead of buying servers ahead of projected peak load, it will pay only for the capacity it actually uses. Which advantage of cloud computing does this describe?

#### Options
- **A.** Trade fixed expense for variable expense **[CORRECT]**
- **B.** Increase speed and agility
- **C.** Go global in minutes
- **D.** Benefit from massive economies of scale

**Correct Answer:** `A`

#### Explanation & Rationale

Paying for what you consume instead of investing up front in hardware is the first of the six advantages of cloud computing: trade capital (fixed) expense for variable expense.

### Question 2

**Domain:** `Domain 1: Cloud Concepts` | **ID:** `cc02`

> **Scenario:**  
> Which of the following is NOT one of the six pillars of the AWS Well-Architected Framework?

#### Options
- **A.** Operational Excellence
- **B.** Reliability
- **C.** Scalability **[CORRECT]**
- **D.** Sustainability

**Correct Answer:** `C`

#### Explanation & Rationale

The six pillars are Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, and Sustainability. Scalability is a property that well-architected workloads have, not a pillar.

> A company keeps its core database in an on-premises data center but runs its web tier on Amazon EC2, with a VPN connecting the two environments. Which cloud deployment model is this?

#### Options
- **A.** Public cloud
- **B.** Private cloud

### Question 4

**Domain:** `Domain 1: Cloud Concepts` | **ID:** `cc04`

> **Scenario:**  
> A retail website automatically adds Amazon EC2 instances during a flash sale and removes them when traffic drops. Which cloud concept does this BEST illustrate?

#### Options
- **A.** Fault tolerance
- **B.** Elasticity **[CORRECT]**
- **C.** Durability
- **D.** Agility

**Correct Answer:** `B`

#### Explanation & Rationale

Elasticity is acquiring resources as demand rises and releasing them when it falls, automatically. Scalability is the ability to grow; elasticity is the dynamic matching of resources to load.

### Question 5

**Domain:** `Domain 1: Cloud Concepts` | **ID:** `cc05`

> **Scenario:**  
> Which statement about AWS Availability Zones is correct?

#### Options
- **A.** An Availability Zone is a single data center in one Region
- **B.** An Availability Zone is one or more discrete data centers with redundant power, networking, and connectivity inside a Region **[CORRECT]**
- **C.** Availability Zones are the same thing as edge locations
- **D.** Each AWS Region contains exactly one Availability Zone

**Correct Answer:** `B`

#### Explanation & Rationale

An AZ is one or more physically separate data centers with independent power and networking. Every Region has multiple AZs connected by low-latency links, which is what lets you build highly available architectures.

> **Scenario *(Select 2)*:**  
> Which AWS services use edge locations to serve users with low latency? (Choose TWO.)

#### Options

- **B.** Amazon Route 53 **[CORRECT]**
- **C.** Amazon EC2
- **D.** Amazon RDS
- **E.** AWS CloudFormation

**Correct Answer:** `A, B`

CloudFront caches content at edge locations and Route 53 answers DNS queries from them. EC2 and RDS run inside Availability Zones, and CloudFormation is a regional provisioning service.

- **B.** Loose coupling **[CORRECT]**
- **C.** Vertical scaling
