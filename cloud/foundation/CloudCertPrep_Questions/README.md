## 🎯 Question Schema Highlights
Each question includes:
- **Unique Question ID**: e.g., `q004`, `q025`.
- **Exam Task / Subdomain**: Aligned with the official CLF-C02 task statements (`1.1`, `1.2`, `2.1`, `3.4`, etc.).
- **Associated AWS Services**: Identified AWS services tested in the question.
- **Single and Multi-Response Formats**: Distinctly labeled single vs. multi-answer questions.
- **Complete Rationales**: Thorough explanations of why the correct option is right and why the distractors are wrong.
