### Question 1

**Domain:** `Domain 1: Cloud Concepts` | **Topic:** `Global infrastructure` | **ID:** `q0007`

> **Scenario:**  
> A company has developed an eCommerce web application in AWS. What should they do to ensure that the application has the highest level of availability?

#### Options
- **A.** Deploy the application across multiple Availability Zones and Edge locations.
- **B.** Deploy the application across multiple Availability Zones and subnets.
- **C.** Deploy the application across multiple Regions and Availability Zones. **[CORRECT]**
- **D.** Deploy the application across multiple VPC’s and subnets.

**Correct Answer:** `C`

#### Comprehensive Explanations

> Correct answer: Deploy the application across multiple Regions and Availability Zones. Availability Zone — one or more discrete data centres inside a Region with independent power and networking, so deploying across two of them removes a single point of failure. This item belongs to the Cloud Concepts domain, under Global infrastructure.

- **Option A** ❌ (INCORRECT): Evaluation of option A.
- **Option B** ❌ (INCORRECT): Evaluation of option B.
- **Option C** ✅ (CORRECT): Correct. Availability Zone — one or more discrete data centres inside a Region with independent power and networking, so deploying across two of them removes a single point of failure.
- **Option D** ❌ (INCORRECT): Amazon VPC — a logically isolated private network in AWS where you define the IP range, subnets, route tables and gateways.
