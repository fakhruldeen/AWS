### Question 1

**Domain:** `Domain 2: Security and Compliance` | **Topic:** `Auditing` | **ID:** `q0003`

> **Scenario:**  
> You have noticed that several critical Amazon EC2 instances have been terminated. Which of the following AWS services would help you determine who took this action?

#### Options
- **A.** Amazon Inspector.
- **B.** AWS CloudTrail. **[CORRECT]**
- **C.** AWS Trusted Advisor.
- **D.** EC2 Instance Usage Report.

**Correct Answer:** `B`

#### Comprehensive Explanations

> Correct answer: AWS CloudTrail. AWS CloudTrail — records every API call in the account including who made it, from which IP address and when, which makes it the service that answers who did this. This item belongs to the Security and Compliance domain, under Auditing.

- **Option A** ❌ (INCORRECT): Amazon Inspector — automatically scans EC2 instances, container images and Lambda functions for known software vulnerabilities and unintended network exposure.
- **Option B** ✅ (CORRECT): Correct. AWS CloudTrail — records every API call in the account including who made it, from which IP address and when, which makes it the service that answers who did this.
- **Option C** ❌ (INCORRECT): AWS Trusted Advisor — inspects the account and recommends improvements across cost optimisation, performance, security, fault tolerance and service quotas.
- **Option D** ❌ (INCORRECT): Amazon EC2 — resizable virtual machines where you choose the instance type, control the guest operating system, and pay per second or hour of runtime.

### Question 2

**Domain:** `Domain 2: Security and Compliance` | **Topic:** `Shared Responsibility Model` | **ID:** `q0005`

> **Scenario:**  
> Which statement is true regarding the AWS Shared Responsibility Model?

#### Options
- **A.** Responsibilities vary depending on the services used. **[CORRECT]**
- **B.** Security of the IaaS services is the responsibility of AWS.
- **C.** Patching the guest OS is always the responsibility of AWS.
- **D.** Security of the managed services is the responsibility of the customer.

**Correct Answer:** `A`

#### Comprehensive Explanations

> Correct answer: Responsibilities vary depending on the services used. Shared responsibility model — AWS secures the cloud itself while the customer secures what they put in it, with the dividing line moving upward as the service becomes more managed. This item belongs to the Security and Compliance domain, under Shared Responsibility Model.

- **Option A** ✅ (CORRECT): Correct.
- **Option B** ❌ (INCORRECT): Infrastructure as a Service — supplies raw compute, storage and networking, giving the most control and leaving the operating system to the customer.
- **Option C** ❌ (INCORRECT): Evaluation of option C.
- **Option D** ❌ (INCORRECT): Evaluation of option D.
