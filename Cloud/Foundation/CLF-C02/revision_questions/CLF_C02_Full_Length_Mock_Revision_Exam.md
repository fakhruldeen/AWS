## 🔑 Mock Exam Answer Key & Quick Explanations

1. **B** — "Go global in minutes" enables global deployment via AWS Regions and Edge Locations.
2. **C** — Hardware retirement and physical data center destruction are AWS responsibilities.
3. **B** — Amazon RDS automates relational provisioning, multi-AZ synchronous replication, and patching.
4. **A** — AWS Compute Optimizer uses ML on CloudWatch metrics to recommend right-sizing.
5. **B** — Amazon Macie discovers and protects sensitive PII in Amazon S3.
6. **B** — Amazon EFS is an elastic POSIX file system supporting concurrent multi-AZ EC2 mounts.
7. **A** — The Governance perspective coordinates cloud initiatives with business governance policies.
8. **B** — IAM Roles supply temporary STS credentials to EC2 instances securely.
9. **B** — Amazon Route 53 is a highly available and scalable cloud Domain Name System (DNS) web service.
10. **B** — The Business Plan provides 24/7 support and 1-hour production SLA, but designated TAM requires Enterprise.
