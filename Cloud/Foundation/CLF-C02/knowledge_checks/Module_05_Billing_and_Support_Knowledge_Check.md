# Module 05 Knowledge Check: Billing & Support

### Questions
1. **Which AWS tool allows you to set custom spend limits and receive alerts via email or SNS when your costs or usage exceed defined thresholds?**
   - A) AWS Cost Explorer
   - B) AWS Budgets
   - C) AWS Pricing Calculator
   - D) AWS Billing Conductor
2. **Which AWS Support Plan is the minimum tier that provides 24/7 phone, chat, and email support from Cloud Support Engineers and a 1-hour response SLA for production system outages?**
   - A) Basic Plan
   - B) Developer Plan
   - C) Business Plan
   - D) Enterprise Plan
3. **What is a designated benefit provided exclusively to AWS Enterprise Support Plan customers?**
   - A) Access to AWS documentation
   - B) A dedicated Technical Account Manager (TAM) and Concierge Support Team
   - C) Free EC2 instances for testing
   - D) 50% discount on S3 storage costs
4. **Which tool provides visual charts to analyze historical AWS spending, identify spending trends, and forecast costs for the next 12 months?**
   - A) AWS Pricing Calculator
   - B) AWS Cost Explorer
   - C) AWS Budgets
   - D) Amazon CloudWatch Billing Alarms
5. **What AWS Organizations feature allows an enterprise to combine resource usage across multiple accounts to qualify for volume pricing discounts?**
   - A) Service Control Policies (SCPs)
   - B) Consolidated Billing
   - C) AWS RAM (Resource Access Manager)
   - D) AWS Control Tower
6. **Which EC2 purchasing option provides the highest cost savings (up to 90%) for fault-tolerant workloads that can tolerate unexpected interruptions?**
   - A) On-Demand Instances
   - B) Spot Instances
   - C) Reserved Instances
   - D) Dedicated Hosts
7. **What is the purpose of AWS Cost Allocation Tags?**
   - A) Encrypting files in S3 buckets
   - B) Labeling resources with key-value pairs (e.g., `Environment=Production`, `CostCenter=HR`) to track costs by business unit
   - C) Speeding up network packet transfers across Regions
   - D) Enforcing MFA on IAM users
8. **Which online tool allows prospective customers and architects to model and estimate the monthly cost of an AWS architecture prior to deployment?**
   - A) AWS Pricing Calculator
   - B) AWS Cost Explorer
   - C) AWS Budgets
   - D) AWS Compute Optimizer
9. **Which service provides automated recommendations across 5 pillars (Cost Optimization, Performance, Security, Fault Tolerance, Service Limits) to optimize your AWS environment?**
   - A) AWS Trusted Advisor
   - B) AWS Inspector
   - C) AWS Systems Manager
   - D) AWS Health Dashboard
10. **What is the curated digital catalog where customers can search, buy, deploy, and manage third-party software licenses and AMIs that run on AWS?**
    - A) AWS Service Catalog
    - B) AWS Marketplace
    - C) AWS Artifact
    - D) AWS Partner Network (APN)

---

### Answer Key & Explanations
| Q# | Answer | Key Concept Reference |
| :---: | :---: | :--- |
| **1** | **B** | AWS Budgets allows you to configure proactive threshold alerts for costs and usage. |
| **2** | **C** | The Business Support plan is the entry tier for 24/7 phone/chat support with a 1-hour production SLA. |
| **3** | **B** | Only Enterprise Support includes a designated Technical Account Manager (TAM) and Concierge team. |
| **4** | **B** | AWS Cost Explorer provides interactive visual analytics, filtering, and forecasting up to 12 months. |
| **5** | **B** | Consolidated Billing aggregates usage across all member accounts to achieve volume discounts. |
| **6** | **B** | Spot Instances leverage spare capacity at up to 90% discount for interruptible workloads. |
| **7** | **B** | Cost Allocation Tags enable cost breakdown by department, project, cost center, or environment. |
| **8** | **A** | AWS Pricing Calculator generates estimated monthly cost proposals before building resources. |
| **9** | **A** | AWS Trusted Advisor scans your environment and provides recommendations across 5 pillars. |
| **10** | **B** | AWS Marketplace offers thousands of verified third-party software products billed directly through AWS. |
