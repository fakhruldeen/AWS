# Lecture 06: Billing, FinOps & CLF-C02 Exam Strategy

## ⏱️ Timing & Delivery Strategy
- **Duration:** 90 Minutes
- **Lecture Slide Deck:** `slides/Module_05_Billing_Pricing_and_Support_Slides.md`

## 🎯 Learning Objectives
1. Compare AWS FinOps tools: **AWS Budgets**, **AWS Cost Explorer**, **AWS Cost & Usage Report (CUR)**, and **AWS Pricing Calculator**.
2. Compare the 4 AWS Support Plans: Basic, Developer, Business, and Enterprise On-Ramp / Enterprise.
3. Master AWS Marketplace software subscription models.
4. Execute test-taking strategies for passing the 65-question CLF-C02 exam (700/1000 passing score).

## 🗣️ Instructor Talking Points & Common Traps
- **Trap 1: Support Plan Response Times & TAM Access:**
  - *Business Plan:* 24/7 phone/chat/email, 1-hour response for production system down. Does **NOT** include a designated Technical Account Manager (TAM).
  - *Enterprise Plan:* 15-minute response for business-critical system down, includes a **designated Technical Account Manager (TAM)** and Concierge Support team.
- **Trap 2: AWS Budgets vs. Cost Explorer:**
  - *AWS Budgets:* **Proactive alerting** before or as costs exceed thresholds (sends SNS / email).
  - *Cost Explorer:* **Visual historical analytics** and forecasting charts (retrospective review).
