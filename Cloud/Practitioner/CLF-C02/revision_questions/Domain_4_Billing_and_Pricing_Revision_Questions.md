# Domain 4: Billing & Pricing Revision Questions (12% Exam Weight)

### Question 1
A financial analyst wants to receive an automated email notification whenever their monthly AWS bill is projected to exceed \$500 before the end of the billing cycle. Which AWS tool should they configure?
- [ ] A) AWS Cost Explorer
- [ ] B) AWS Budgets
- [ ] C) AWS Pricing Calculator
- [ ] D) AWS Cost and Usage Report (CUR)
> **Correct Answer:** B  
> **Rationale:** AWS Budgets allows you to set custom spending limits and receive proactive email/SNS notifications when your actual costs or forecasted costs exceed your defined threshold.

---

### Question 2
An enterprise customer requires 24/7 access to Cloud Support Engineers via phone, chat, and email, a response time of less than 15 minutes for business-critical system outages, and a designated Technical Account Manager (TAM). Which AWS Support Plan must they purchase?
- [ ] A) Developer Support Plan
- [ ] B) Business Support Plan
- [ ] C) Enterprise Support Plan
- [ ] D) Basic Support Plan
> **Correct Answer:** C  
> **Rationale:** Only the Enterprise Support Plan provides a designated Technical Account Manager (TAM), Concierge Support team, and a 15-minute response SLA for business-critical system down incidents.

---

### Question 3
Which AWS billing feature allows an enterprise to consolidate payment for multiple AWS accounts into a single payer account and benefit from volume pricing tiers across all accounts?
- [ ] A) AWS Cost Categories
- [ ] B) Consolidated Billing in AWS Organizations
- [ ] C) AWS Cost Allocation Tags
- [ ] D) AWS Billing Conductor
> **Correct Answer:** B  
> **Rationale:** Consolidated Billing within AWS Organizations combines usage across all member accounts to reach volume discount tiers (e.g., S3 tiering) faster and pays all invoices from one master account.

---

### Question 4
Which free AWS tool provides recommendations for optimal compute resource sizing (EC2, Lambda, EBS) by utilizing machine learning to analyze historical Amazon CloudWatch utilization metrics?
- [ ] A) AWS Compute Optimizer
- [ ] B) AWS Cost Explorer Rightsizing Recommendations
- [ ] C) AWS Trusted Advisor Cost Pillar
- [ ] D) AWS Well-Architected Tool
> **Correct Answer:** A  
> **Rationale:** AWS Compute Optimizer applies machine learning to CloudWatch metrics (CPU, memory, storage IOPS) to recommend optimal instance types, eliminating over-provisioned spend.

---

### Question 5
Which purchasing model offers the highest flexibility by applying a committed hourly spend (e.g., \$10/hour for 1 or 3 years) across any EC2 instance family, AWS Lambda, or AWS Fargate usage regardless of region or OS?
- [ ] A) Standard EC2 Reserved Instances
- [ ] B) Compute Savings Plans
- [ ] C) EC2 Instance Savings Plans
- [ ] D) Spot Instances
> **Correct Answer:** B  
> **Rationale:** Compute Savings Plans provide the greatest flexibility, automatically reducing costs on EC2 instances (any family, OS, region), AWS Fargate, and AWS Lambda in exchange for a committed hourly spend.
